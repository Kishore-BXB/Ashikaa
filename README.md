# Happy Boyfriend's Day, My Love 💖 — Romantic Digital Scrapbook

A romantic, interactive digital scrapbook application designed with love to celebrate Boyfriend's Day.

## 🌟 Features
- **Scrapbook Aesthetic**: Custom Polaroid frames, photo wheels, washi tape, stamps, and heart stickers.
- **Multiple Visual Themes**: Kisses & Bows, Gingham, Lavender, Sky Blue & Bear Tulips, Sage Cream.
- **Interactive Components**: Photo galleries, memory timelines, audio chimes, modal viewports, and customizable stickers.
- **Responsive Layout**: Designed for seamless viewing across mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- **HTML5 & CSS3**: Vanilla CSS with custom properties (CSS variables), typography scale, and responsive grid/flexbox layouts.
- **JavaScript**: Pure client-side interactive UI logic.
- **Fonts**: Google Fonts (`Playfair Display`, `Caveat`, `Sacramento`, `Plus Jakarta Sans`, `Lora`, `Dancing Script`).

## 🚀 Local Setup & Running
No build step or complex installation is required.

1. **Option A — Simple HTTP Server (Recommended)**
   ```bash
   npx serve .
   ```
   Open `http://localhost:3000` in your web browser.

2. **Option B — Double-click / Live Server**
   Simply open `index.html` in any web browser or use VS Code Live Server.

## ☁️ Deployment Instructions (Vercel)

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Prepare project for production deployment"
   git push -u origin main
   ```
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Select **Import Git Repository** and choose your repository (`Kishore-BXB/ashika`).
4. Framework Preset: **Other** / **Static HTML**.
5. Click **Deploy**. Vercel will instantly host your live site.
